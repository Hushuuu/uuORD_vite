# ORDR 角色技能整理：傳說／隱藏

## 匯入狀態

有明確資料的效果已補入角色 `skills`；以下保留原調研底稿，完整匯入範圍與待補項目見 [調研總索引](ordr-skills-index.md)。

整理日期：2026-10-30。角色名稱與 `character_id` 對應本專案 `src/js/ord_data.js`；技能依來源網站目前內容，以繁體中文摘要整理。此文件是後續填寫 `skills` 的工作底稿，已有資料者已補入 `skills`。

## 範圍與來源

- 本地傳說 41 筆、隱藏 23 筆；依使用者指定略過墓碑（5-10）、殭屍將軍（5-41）、海賊船（6-10），以下保留傳說 39 筆、隱藏 22 筆，共 61 筆。
- 主要來源：[ORDR 角色圖鑑](https://ordr.kr/character)，已閱讀傳說 39 位、隱藏 22 位的個別頁面。ORDR 是非官方資料站；本文採用頁面技能欄，不採用其 AI 評價或配隊推論。
- 全文依網站目前內容整理，不回推歷史版本、不列版本差異。
- 沒有命名的技能使用「【整理名】」作為辨識名稱，並非遊戲正式技能名。翻譯名稱為暫譯，少數技能附韓文便於核對。
- 「主動」表示有操作指令或明確手動目標；「魔力／能量觸發」不逕自認定為手動技能，之後填 `type` 前仍應確認遊戲操作。
- 「光環／常駐」依頁面上方增減益欄整理；來源未提供半徑、持續時間或疊加條件時，不自行補值。
- 「生命能量」表示原文以自身體力作為技能資源，與敵人的目前／最大／已損失生命比例傷害分開記錄。
- 「固定傷害」「爆發型傷害」分別對應 `고정데미지`、`폭발형 데미지`；不能直接互換成物理、魔法或無視防禦。
- 範圍數值沿用遊戲單位。「攻擊時機率」不表示每秒機率；明確的絕對冷卻另外記錄。

## 傳說（level 5）

### 5-1｜光月時

來源：[ORDR：토키](https://ordr.kr/character/L35)

- **摘要**：緩速、攻速支援與機率範圍魔法傷害。
- **光環／常駐**：移速降低 25%；攻速增加 20%。
- **時間果實**：攻擊 10% 觸發，400 範圍 25 萬魔法傷害，單體另加 25 萬魔法傷害。
- **【整理名】時間加速**：每 9 秒選取自身周圍 450 範圍內 2 名傳說以上單位，可包含自身；攻速 +35%，持續 6 秒。離開範圍仍保留效果，範圍內出現新單位時更新目標；不可與其他加速技能重複。

## 後續填入 skills 的方式

1. 以每節標題的本地 `character_id` 找角色，不能直接拿網站的 `L35`、`H15` 當本地 ID。
2. 每個具名技能或可獨立說明的效果建立一個物件；光環可單獨用「【整理名】支援效果」彙整。
3. 將「摘要」改寫成角色／技能簡述；效果數值放 `description`。不把本文件的「待核」文字誤當確定機制。
4. `type` 只在確認主動／被動時填 `active`／`passive`；魔力自動施放、生命能量觸發尚未確認者先用空字串。
5. 【整理名】可用於內部草稿；正式發布前決定保留描述式名稱，或以遊戲正式名稱替換。
6. 標色採現有 `{physical|…}`、`{magic|…}`、`{control|…}`、`{buff|…}`、`{chance|…}`、`{important|…}`。固定／爆發型傷害先用 `important` 強調，避免誤分類。
7. 來源連結保留在這份 Markdown；現有技能欄位先沿用 `id`、`name`、`type`、`summary`、`description`，不擅自增加來源欄位。

格式示意（不代表任何真實角色）：

```json
{
  "id": "skill-stable-id",
  "name": "技能正式名稱或描述式名稱",
  "type": "",
  "summary": "簡述技能的作用。",
  "description": "攻擊時以 {chance|來源機率} 觸發。\n造成 {magic|來源魔法傷害}，並附加 {control|來源控制效果}。"
}
```
