# ORDR 技能整理：常見／不凡／特別／稀有

## 匯入狀態

有明確資料的效果已補入角色 `skills`；以下保留原調研底稿，完整匯入範圍與待補項目見 [調研總索引](ordr-skills-index.md)。

整理日期：2026-10-30。對應本地 100 筆資料，依 [ORDR 圖鑑](https://ordr.kr/character)及各角色目前頁面整理，已有資料者已寫入 `skills`。

常見／不凡主要是合成材料；特別、稀有的許多個別頁也只提供配方。下列「未登錄」指網站未提供技能，**不代表遊戲中沒有技能**。有數值的效果照錄為摘要；來源未具名者使用【整理名】，半徑、目標與疊加未列明時不補造。
